Token Pruning Schedule (7B, 32 layers)
================================================================================

Stage 1: SKIPPED (No THCP)
  - Keep all 576 visual tokens

Stage 2: Progressive Pruning (Front-Heavy Strategy)
  - Layers 0-1 (2 layers): 576 tokens (original)
  - Layers 2-11 (10 layers): 192 tokens (Layer 2: 576 → 192) ← Keep more in front
  - Layers 12-23 (12 layers): 64 tokens (Layer 12: 192 → 64)
  - Layers 24-31 (8 layers): 32 tokens (Layer 24: 64 → 32) ← Aggressive at back

Average visual tokens: 128.00 (exact)
Schedule: [(2, 192), (12, 64), (24, 32)]
Verification: (576×2 + 192×10 + 64×12 + 32×8) / 32 = (1152 + 1920 + 768 + 256) / 32 = 128.00 ✓

Strategy: Front-heavy design keeps more tokens in first ~14 layers for rich semantic info

================================================================================
Schedule Comparison: Uniform vs Front-Heavy
================================================================================

1. **Uniform Schedule** (SparseVLM-aligned):
   - Schedule: [(2, 320), (5, 128), (9, 64)]
   - Distribution: Early pruning, uniform reduction
   - POPE F1: 65.7%
   - Characteristics: High precision (>91%), low recall (50.3%)

2. **Front-Heavy Schedule** (Current):
   - Schedule: [(2, 192), (12, 64), (24, 32)]
   - Distribution: Keep more tokens in first 14 layers, aggressive after layer 14
   - POPE F1: 77.7% ✨ (+12.0 percentage points, +18.3%)
   - Characteristics: High precision (>91%), improved recall (65.6%)

Key Improvements with Front-Heavy Schedule:
  ✅ F1 Score: 65.7% → 77.7% (+12.0 pp)
  ✅ Accuracy: 72.7% → 80.4% avg (+7.7 pp)
  ✅ Recall: 50.3% → 65.6% (+15.3 pp) 🔥
  ✅ Precision: Maintained at >91%

Critical Finding: Front-heavy schedule significantly improves recall!
  → Early layers need more visual tokens to capture object details
  → Better object coverage reduces false negatives
  → Maintains low hallucination (high precision preserved)

Comparison to Baseline
================================================================================

  - Suitable for production applications requiring both speed and accuracy
